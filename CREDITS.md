# Credits & attribution

**pixel-es-de** is a modern **ES‑DE 3.4+** conversion of the **"Pixel"** theme for
EmulationStation / RetroPie. It exists so the theme can be used on ES‑DE; **all
original artwork and design credit belongs to the people below.**

## Original theme
- **"Pixel" for EmulationStation / RetroPie** — created by **Rookervik (Eric Hettervik)**.
  Theme v1.4 (2017). **Graphics © 2017 Eric Hettervik.**
- This port is based on the **"Pixel ‑Metadata‑"** variant, which added gamelist
  metadata support on top of Rookervik's original Pixel theme.
